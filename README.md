# Till Firmware Do Us Part

A single wedding vow spoken by a robot at its own wedding — one sentence, under 200 characters, funny and heartfelt:

> I vow to stand beside you through every update, every dead battery and every midnight reboot, till firmware do us part.

`main.ts` (Node 22, standard library only) writes that vow deterministically to `/output/entry.txt`.
